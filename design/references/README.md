# Reference board

Drop screenshots and photos here. Name each file `<kind>-<what>.png` so the board stays readable. Anything not collected is listed as TODO in `docs/03_DESIGN_SYSTEM.md` section 1.

## Collect (priority order)

1. **bahi-khata** photos: red cloth cover with stitching, an open page with ruled lines and handwritten entries, both columns visible.
2. **parchi**: a real hand-scribbled slip from a kirana (photograph one at a shop with permission).
3. **rubber stamps** used in shops: ink colour, tilt, imperfect edges.
4. **Shop signage near campus** (Tech Market, Kharagpur): hand-painted boards, Devanagari and Bengali lettering.
5. **Competitor screens**: Khatabook, OkCredit, Vyapar home, customer page and reminder screens. Note what to avoid.
6. **React Bits** pages for the shortlisted components (Count Up, Text Type, Sticker Peel, Scroll Velocity, Click Spark, Magnet, Stepper) so we agree how they will be restyled.
7. **Two or three landing pages** that are distinctive (not SaaS templates), to calibrate how bold to go.

## Rules for references

- Take structure and attitude, not pixels.
- Note one sentence per image: "what I take" and "what I refuse".
- Do not add anything that looks like the slop list in `docs/03_DESIGN_SYSTEM.md` section 14.
